# CLAUDE.md — dev context for Claude Code in this repo

TraceRazor: offline auditor for AI-agent token waste. Rust workspace (the auditor) +
Python package (`tracerazor`, release line 1.2.0) with the pure-Python `tracerazor-trice`
proof/compression CLI.

## Build & test

On Windows `cargo` may not be on PATH. In PowerShell, first:
`$env:PATH = "$env:USERPROFILE\.cargo\bin;$env:PATH"`.

```bash
cargo build --release -p tracerazor     # auditor binary -> target/release/tracerazor[.exe]
cargo test --workspace                   # Rust tests
python -m pytest -q                       # Python tests (python 3.11)
```

Some TRICE tests shell out to a bare `python -m pytest`, so run pytest with the venv's
`python` first on PATH (activate the venv), or they fail spuriously. `find_binary()`
prefers a wheel-bundled `tracerazor/bin/tracerazor` over `TRACERAZOR_BIN`; delete that
gitignored copy after `scripts/build_platform_wheel.sh`, or tests use a stale binary.

Run the auditor:
`tracerazor audit traces/support-agent-run-2847.json --hermetic --format json`.
Always `--hermetic --format json` for reproducible machine runs. Traces need ≥ 5 steps
(`--min-steps N`, clamped ≥ 2). Exit codes: 0 ok · 1 only an explicit gate failed
(`--threshold` / regression / TAMPERED) · 2 bad input.

## Honesty rules (project culture — non-negotiable)

- The TAS is **ordinal, not cardinal**: compare the same agent over time, never across
  agents or against an absolute bar.
- `savings.*` and every `estimated_token_savings` are **estimates/projections**, real
  only after a measured before/after `tracerazor bench` at constant task success.
- Never invent numbers, grades, or claims not in the JSON; never quote the README's
  illustrative $/month figures as measured.

## Do not modify

`target/`, `.git/`, `.claude/worktrees/`, `benchmark/trice/results/`, `dist/`, `paper/`,
`.env`, version numbers (stay aligned with 1.2.0), and the generated proof cards
`docs/trice_*_card.*`, `docs/trice_protocol_lock.*`, `docs/trice_suite_readiness.*` and
`docs/trice_release_evidence.*` (regenerated by `tracerazor-trice`, not hand-edited).
`docs/trice_library.md` and `docs/trice_research_ledger.md` are hand-written.

The cards hash-bind their inputs: `pyproject.toml`, `README.md`, every `Cargo.toml`,
`.github/workflows/*`, `docs/public_trust_matrix.md`, `docs/release_checklist.md`,
`docs/trice_library.md`, `schemas/trice_*`, and `examples/trice_*`. After editing any of
them, regenerate the affected `docs/` cards with `python -m tracerazor.trice <card> --out
<the card's existing docs/ path>` and check each with `verify-<card>`. `paper/` copies are
left alone.
