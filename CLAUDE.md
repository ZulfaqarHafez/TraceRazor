# CLAUDE.md — dev context for Claude Code in this repo

TraceRazor: offline auditor for AI-agent token waste. Rust workspace (the auditor) +
Python package (`tracerazor`, release line 1.1.0) with the pure-Python `tracerazor-trice`
proof/compression CLI.

## Build & test

`cargo` is not on PATH. In PowerShell, first:
`$env:PATH = "$env:USERPROFILE\.cargo\bin;$env:PATH"`.

```bash
cargo build --release -p tracerazor     # auditor binary -> target/release/tracerazor[.exe]
cargo test --workspace                   # Rust tests
python -m pytest -q                       # Python tests (python 3.11)
```

Run the auditor:
`tracerazor audit traces/support-agent-run-2847.json --hermetic --format json`.
Always `--hermetic --format json` for reproducible machine runs. Traces need ≥ 5 steps
(`--min-steps N`, clamped ≥ 2). Exit codes: 0 ok · 1 only an explicit gate failed
(`--threshold` / regression / TAMPERED) · 2 bad input.

## Honesty rules (project culture — non-negotiable)

- The TAS is **ordinal, not cardinal**: compare the same agent over time, never across
  agents or against an absolute bar.
- `savings.*` and every `estimated_token_savings` are **estimates/projections**, real
  only after a measured before/after `tracerazor bench` at constant task success.
- Never invent numbers, grades, or claims not in the JSON; never quote the README's
  illustrative $/month figures as measured.

## Do not modify

`target/`, `.git/`, `.claude/worktrees/`, `benchmark/trice/results/`, `dist/`, `paper/`,
`.env`, version numbers (stay aligned with 1.1.0), and the generated `docs/trice_*` proof-card
artifacts (regenerated by `tracerazor-trice`, not hand-edited).
